# PointAndIdentify

אפליקציית Android לזיהוי היישוב שאליו מכוונת המצלמה, בדיקת נראות טופוגרפית מול מודל גבהים (DEM), ותיעוד בתמונה עם שכבת מידע ו-EXIF.

## 1. יכולות

1. מצלמה חיה עם כוונת ושכבת מידע (שם יעד, טווח, אזימוט, גלוי/מוסתר).
2. אזימוט צפון אמת מ-`TYPE_ROTATION_VECTOR`, עם remap לטלפון אנכי, החלקה ותיקון סטייה מגנטית.
3. קו ראייה מול DEM ברזולוציה של 1″ (~30 מ'), כולל עקמומיות כדור הארץ ושבירה (k=0.13).
4. משיכה מ-GitHub של אריחי גובה ברדיוס 50 ק"מ בלבד סביב המיקום (הקרובים קודם), עם מטמון מקומי ואימות SHA-256.
5. יעדים עד 50 ק"מ, כולל רצועת הגבול של המדינות השכנות: יישובים, הרים ופסגות, מגדלים ותרנים, מגדלורים, ארובות, מגדלי מים, מבצרים, חורבות ואנדרטאות.
6. שכבת נתונים במסך ובתמונה, כל נתון בשורה נפרדת: מיקום הצופה ודיוקו, גובה עין, זווית אנכית, סוג היעד, גובהו, מיקומו, טווח, אזימוט, זווית ליעד ומרווח קו ראייה. אזימוט המצלמה מוצג מתחת למצפן. נתוני היעד נשמרים גם בתגי GPSDest ב-EXIF.
7. עדכון מאגר היעדים לפי גרסה ב-`manifest.json`.
8. **הגדרות** (גלגל שיניים בתחתית המסך) – החלפת שפה (עברית ברירת מחדל, אנגלית) ובדיקת עדכון: בדיקת ה-Release האחרון, הורדת APK, אימות SHA-256 והפעלת המתקין.
9. זום: סרגל אנכי בצד ימין (מינימום למטה, מקסימום למעלה, ערך הזום ליד הידית) וצביטה במסך. מעל הזום של המצלמה פועל זום נוסף מחושב (עד ×4, חיתוך דיגיטלי גם בתמונה). הכוונת גדלה וחלון הבחירה מצטמצם עם הזום.
10. לחיצה בתוך הכוונת – רשימת היעדים שבכוונת, מדורגת לפי סטייה מהצלב, גלוי/מוסתר וזווית אנכית. מצפן קטן בצד שמאל מצביע לצפון אמת. כפתור **עזרה** (?) מציג הסברים על האפליקציה.
11. כפתור **יציאה** – עצירת חיישנים, מיקום ומצלמה וכיבוי מלא של התהליך.
12. בדיקת מצפן בהפעלה: עוצמת שדה מגנטי, כיול ויציבות הכיוון, עם הנחיה ובדיקה חוזרת. במקביל נבדק עדכון גרסה (שקט אם אין עדכון).
13. כפתור **מצא** – חיפוש חופשי של "בית" (נקודה פרטית), יישוב, כתובת או קואורדינטות. חץ צמוד לחלק החיצוני של הכוונת מצביע לאן להזיז את המצלמה; כשהמקום בתוך העיגול מופיעה טבעת.
14. טבלת הנתונים קבועה ומציגה תמיד את כל השורות ("–" לנתון חסר). מיקום היעד מוצג רק כשהטלפון מורם; במצב אופקי מוצג רק המיקום הנוכחי.

## 2. מבנה

| נתיב | תוכן |
|---|---|
| `app/` | קוד האפליקציה (Kotlin) |
| `data/manifest.json` | אינדקס האריחים והיישובים |
| `data/tiles/` | אריחי גובה `<lat>_<lon>.bin.gz` |
| `data/targets.json` | מאגר יעדים (יישובים וציוני שטח) |
| `tools/` | סקריפטי Python לבניית הנתונים |
| `.github/workflows/` | בניית Release ובדיקת נתונים |

## 3. הפעלה אוטומטית

### 3.1 הקמה חד-פעמית (Windows)
1. התקנות: Git for Windows, GitHub CLI (`gh`), ו-Android Studio (לכלי `keytool`).
2. עבודה ישירות בשכפול המקומי של המאגר (סקריפטי ההעלאה הישנים הועברו לארכיון מחוץ למאגר).
3. ההקמה החד-פעמית (מפתח חתימה, ארבעת ה-Secrets מסוג `POINT_*`, GitHub Pages מ-`main` / `/docs`) בוצעה. מפתח החתימה נמצא ב-`%USERPROFILE%\PointAndIdentify-signing` (יש לגבות תיקייה זו).
4. התקנה בטלפון: `https://github.com/eldadgalker-dev/PointAndIdentify/releases/latest/download/PointAndIdentify.apk`

### 3.2 מה קורה אוטומטית אחר כך
| אירוע | מה רץ | תוצאה |
|---|---|---|
| קוד האפליקציה השתנה ב-`main` | `release.yml` | APK חתום ו-Release בגרסה `<versionBase>.<מספר הרצה>`; הטלפונים מתעדכנים דרך **הגדרות ← בדוק עדכון גרסה** |
| כלי הנתונים השתנו, או ה-1 בכל חודש | `data.yml` | יעדים מ-OSM, הורדת גבהים, אריחים ומניפסט; commit אוטומטי ל-`data/` |
| קובץ נתונים השתנה | `data-check.yml` | אימות שהמניפסט תואם לקבצים |

עדכון שוטף: עבודה ישירה במאגר עם Claude Code (הנחיות בקובץ `CLAUDE.md`).

גרסה ראשית ומשנית: `point.versionBase` ב-`gradle.properties`.

## 4. נתונים

1. **יעדים:** `tools/build_targets.py`. כל היעדים בעלי שם בתחום ISO3166-1=IL ב-OSM, ובנוסף יעדים במדינות השכנות עד 50 ק"מ מיישוב בתחום. 50 ק"מ הוא טווח היעד של האפליקציה, ולכן יעד רחוק יותר לא יכול להיבחר. הפרמטר: `--buffer-km`.
2. **גבהים:** `tools/fetch_dem.py` מוריד את תאי ה-1° הדרושים מ-Terrain Tiles (ללא חשבון). תא שאינו קיים במקור (HTTP 404) מטופל כים; כל שגיאה אחרת עוצרת את הריצה.
3. **אריחים:** `tools/build_dem_tiles.py` חותך רק את רצועת ה-buffer, ובונה את `manifest.json`.
4. **ים ונתונים חסרים:** אריח ב-`sea.json` מטופל כגובה 0; אריח שאינו ברשימת היבשה ואינו ברשימת הים מטופל כלא ידוע.
5. הרצה ידנית אפשרית: `pip install -r tools/requirements.txt`, ואז שלושת הכלים לפי הסדר (`fetch_dem.py --out <dir>`, ואז `build_dem_tiles.py --input <dir> --missing-as-sea`).

## 5. מגבלות

1. דיוק מצפן טלפון טיפוסי: ±3–5° (הערכה). ב-50 ק"מ סטייה של 4° היא כ-3.5 ק"מ הצידה.
2. עדכון עצמי – להפצה ישירה בלבד; מחייב אישור "התקנה ממקורות לא ידועים".
3. גרסה שנבנתה מקומית במפתח debug לא תתעדכן מ-Release (חתימה שונה).
